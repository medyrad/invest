# پژوهش و تصمیم فنی

قواعد از HTML و TS واقعی استخراج و اختلاف‌ها با D26/D29/D32 مقابله شدند. پژوهش‌ها در mapping همراه locator تثبیت می‌شوند. AST/exports منبع فقط ابزار پژوهش ignored است و runtime محصول نیست.

تصمیم: Draft/Report/Case/file/session موجود گسترش یابد؛ علت: حفظ دسترسی و تاریخچه و جلوگیری از دو سامانه. جایگزین ردشده: فرصت صوری یا کارتابل موازی. snapshot خدمت و CHECK موضوع افزایشی‌اند.

تصمیم: استخراج metadata ثابت و evaluator بومی Python؛ علت: تمام شرط‌ها/اثرها server authoritative و بدون وابستگی DOM. جایگزین ردشده: iframe یا eval کد HTML/JS داخل محصول.

تقدم D32 بر Office/ZIP/WebP قدیمی ایده؛ PDF/JPEG/PNG با اسکن واقعی و سقف مصوب مدارک. منبع proposal فقط gap دارد؛ total_need و existing_resources افزوده صریح مأموریت‌اند، نه تفسیر gap. ارز خارجی بدون تبدیل و ضریب خیریه ناموجود بدون نتیجه عددی. block ارزیابی را با منع درخواست کمک یکی نمی‌کنیم.

Clarify: ابهام مسدودکننده نیازمند تصمیم تازه یافت نشد؛ پرسش‌های تحقیق از منبع/مأموریت پاسخ دارند. عرضه، retention واقعی، کانال بیرونی و AI متصل گیت مستقل‌اند و مصوب فرض نشده‌اند.
