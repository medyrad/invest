# پژوهش و تصمیم‌های طرح

۲۰۲۶/۱۱/۱۷ — پیشنهادهای فنی از توافق بیزینسی جدا هستند.

| موضوع | نتیجه/دلیل | جایگزین و تعیین تکلیف |
|---|---|---|
| منبع | advisor برای بیزینس و UI؛ ham فقط کیفیت و تحویل؛ دستورهای داخل ZIP اختیار نیستند | کپی دامنه یا طراحی ham رد شده با دستور کاربر |
| فرانت | حفظ Next/React و asset/font/component مرجع احتمال تغییر بی‌دلیل طرح را کم می‌کند؛ تطبیق تصویر لازم است | Vite صرفاً برای هم‌شکلی ham مزیت اثبات‌شده ندارد |
| بک‌اند | Django/DRF ماژولار و PostgreSQL؛ کنترل مجوز و تراکنش یکجا | microservice در ابتدا نیاز ندارد |
| نشست | مبدأ مشترک، cookie HttpOnly و CSRF؛ cache خصوصی جدا | token در localStorage منبع حقیقت نخواهد بود |
| انتشار | فرصت پایدار + revision + public_revision؛ تأیید اتمیک | تغییر مستقیم رکورد عمومی با D11 ناسازگار است |
| AI | OpenAI مصوب؛ adapter و ابزار محدود، مصرف اتمیک | مدل/اعداد سهمیه انتخاب نشده؛ throttle معمول DRF سقف قطعی هزینه نیست |
| تست | PostgreSQL واقعی، چندحسابی، idempotency، browser و screenshot؛ smoke واقعی جدا از mock | build یا screenshot تنهایی پذیرش بیزینس نیست |
| فرم‌های پویا | ۴۰۰ رخداد تعریف شامل ۳ عنوان؛ ۵۲ تابع منتخب قواعد؛ شمارش اولیه ۶۷ جامع نبود | occurrence معادل فیلد مستقل نیست؛ تطبیق معنایی باز است |
| SpecKit | CLI رسمی 1.4.1 با integration codex/skills، bootstrap جدا و انتقال فایل‌های ابزار | نصب global موجود تغییر نکرد؛ ham اثبات استفاده تاریخی از CLI رسمی ندارد |

[پژوهش معماری با منابع رسمی](../../docs/stage1/research-architecture.md) و [ممیزی پویا](../../docs/stage1/dynamic-source-audit.md) شاهد تفصیلی‌اند. نسخه‌های پیشنهادی در plan؛ patch در S02 بررسی می‌شود. [نصب رسمی SpecKit](https://github.github.com/spec-kit/installation.html)، [انتشار 1.4.1](https://github.com/github/spec-kit/releases/tag/v1.4.1).

هیچ مجهول بیزینسی با «انتخاب فنی» بسته نشده است. B01 با پاسخ صریح کاربر در D25 بسته شد؛ تماس/نمایندگی B03 در D26/D27 بسته شد؛ B02 در D28 بسته شد و B04 نیز در D29 تأیید شد؛ کالیبراسیون رتبه‌بندی با کارشناس محصول هنوز انجام نشده است. [B01–B08](../../docs/stage1/review-packet.md) فهرست موضوع، پیشنهاد و گیت را نگه می‌دارد. گیت پژوهش برای plan اجرایی نهایی هنوز باز است؛ خروجی فعلی بستهٔ بازبینی است.
