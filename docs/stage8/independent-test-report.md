**بازبینی تصویر و حدود آن**

۱۰جفت baseline موجودِ فهرست/۹فرم مرجع و محصول در۱۴۴۰ واقعاً کنار هم دیده شدند؛ این مشاهده تازه است، ضبط این۱۰جفت متعلق به تحویل قبلی است. پوسته/تصاویر/هویت کلی حفظ شده‌اند. تصویر تازهٔ جمع‌بندی۹خدمت و زمین۳۶۰/۷۶۸/۱۴۴۰، اسکان۳۹۰، خیریه غیرنقدی۳۶۰، و HTML دانلودشده در۳۶۰ هم بازبینی شد.
