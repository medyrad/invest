# گزارش PROGRAMMER-S03-01 — ورود و نشست آزمایشی invest

تاریخ: ۲۰۲۶/۱۱/۱۷. وضعیت تحویل: **آماده آزمون مستقل**؛ پذیرش نهایی S03 و تأیید انسانی طراحی با هماهنگ‌کننده و کاربر است. این گزارش مجوز S04، انتشار عمومی یا اتصال واقعی نیست.

## خروجی قابل استفاده

آدرس اجرای محلی: **http://127.0.0.1:3108**. «ورود به حساب» → شماره مصنوعی ایران → دریافت کد شش‌رقمی در اعلان همان پنجره → بررسی سروری → نمایش وضعیت حساب → reload → خروج. قالب‌های09/+98/0098 و ارقام فارسی/عربی/لاتین پذیرفته می‌شوند؛ ورودی نامعتبر بریده نمی‌شود. کد ثابت یا پذیرش هر کد وجود ندارد. اعلان صریحاً آزمایشی است و mobile_verified_at را پر نمی‌کند. پیامک واقعی ارسال نمی‌شود.

خطا، loading، انتظار، انقضا، ویرایش شماره و resend قابل استفاده‌اند. این تحویل پوسته فعلی را به ورود/خروج مجهز می‌کند؛ صفحه کامل S04 یا ذخیره S07 ساخته نشده و پیام «ذخیره شد» وجود ندارد.

## امنیت و قراردادهای اجراشده

مصرف کد، سهمیه، بررسی و ابطال با transaction و قفل advisory مشترک PostgreSQL ترتیب می‌گیرند؛ زمان پس از قفل سنجیده می‌شود. پنجره‌ها لغزان و مرز ابتدا خارج است. صدور پذیرفته‌شده سهمیه می‌گیرد؛ خطای تحویل پس نمی‌دهد و retry مصرف تازه ندارد. REMOTE_ADDR مبناست و X-Forwarded-For دلخواه پذیرفته نیست. پشت proxy فعلی IP قابل مشاهده IP همان proxy است؛ تنظیم و ظرفیت عملیاتی پیش از عرضه لازم است.

جریان/رسید۳۰دقیقه، کد۱۲۰ثانیه و حداکثر پنج خطا؛ پس از مصرف/انقضا/جایگزینی، retry آن را زنده نمی‌کند. پاسخ گم‌شده verify فقط با cookie دریافت‌شده و me بازیابی می‌شود؛ بدون cookie ورود تازه لازم است. replay نشست تازه نمی‌سازد و خروج را خنثی نمی‌کند. adapter SMS پیکربندی‌نشده503 می‌دهد؛ unknown شبیه‌سازی شد و retry دوباره adapter را صدا نمی‌زند. تضمین ارسال واقعی یک‌باره داده نشده است.

نشست عادی/حساس، سقف idle/absolute، چرخش بدون تمدید absolute، freshness پنج‌دقیقه و ابطال epoch آزموده‌اند. فقط activity موفق idle را تمدید می‌کند؛ me/poll/health خیر. نقش از payload رد می‌شود. test evidence در public و عملیات حساس واقعی پذیرفته نیست؛ fixture واقعی مصنوعی فقط برای آزمون پایه اختیار استفاده شد. ارتقای نقش نشست قبلی را باطل می‌کند؛ روش واقعی ورود حساس هنوز فعال نشده است. تغییر اختیار باید از service/قفل User.save بگذرد؛ QuerySet.update و SQL مستقیم مسیر مجاز مدیریت اختیار نیستند.

نیت۱۰دقیقه، snapshot ثابت و مصرف اتمیک دارد؛ حساب و نشست متصل و مقصد allowlist هنگام مصرف بررسی می‌شوند. تعویض حساب و بازگشت، نیت قبلی را قابل مصرف نمی‌کند. خروجی فقط handoff با persisted=false است؛ پذیرش ذخیره واقعی به S07 تعلق دارد.

## بازتولید، محدودیت و قدم بعد

[راهنمای توسعه](../development.md) و [quickstart](../../specs/005-identity-session/quickstart.md) فرمان‌ها را دارند. env واقعی موجود حفظ شد؛ `dev_env.py` برای محیط خالی راز محلی تولید می‌کند و آن را چاپ نمی‌کند. `make browser` فقط DB مصنوعی *_browser را بازسازی می‌کند و داده برنامه را حذف نمی‌کند. image backend بعد از تغییر کد باید rebuild شود. runtime web/backend/db محلی برقرار می‌ماند؛ API و سرورهای موقت تست/مرجع پس از ثبت شواهد متوقف می‌شوند.

قفل سراسری هویت برای این نسخه ساده و چندworker-safe است؛ ظرفیت عرضه با آن تأیید نشده است. نگهداری فعلی مصنوعی سیاست داده واقعی نیست؛ TTL منطقی جریان۳۰دقیقه، مجوز نگهداری عملیاتی audit یا backup نیست. SMS/OpenAI واقعی، روش ورود حساس واقعی، بازیابی حساب، نمایندگی کامل S05، مسیر واقعی D26 در S06، ذخیره S07 و کل محصول تأیید نشده‌اند. همه فرمان‌های سرویس به پروژه Compose invest محدود بودند؛ deploy، push و مرحله بعد اجرا نشدند.

قدم مشخص بعد: آزمون مستقل PROGRAMMER-S03-01 و بازبینی تصاویر/گیت‌های S03 توسط هماهنگ‌کننده و کاربر؛ شروع آن یا مرحله بعد نیازمند دستور بعدی است.
