# پیشنهاد تصمیم پیش از داده واقعی

وضعیت: پیشنهاد، **تصمیم مصوب یا قانون محصول نیست**. اکنون داده مصنوعی است و نسخه‌های ارسال‌شده/تأییدشده، audit و مدارک مورد استناد purge نمی‌شوند. حذف موقت/سطل طبق D30 فقط روی داده بی‌ارجاع اجرا می‌شود.

پیشنهاد برای تصمیم هماهنگ‌کننده: نسخه و گفتگو/پیوست پرونده تا۱۲ماه پس از پایان آخرین فرصت یا پرونده مرتبط، و audit تصمیم/دسترسی تا۲۴ماه نگه داشته شوند؛ پس از آن حذف محتوا و نگهداری حداقل رسید غیرمحتوایی ارزیابی شود. این اعداد گزینه مهندسی برای برآورد هزینه و بازیابی اختلاف‌اند، نه توصیه یا ادعای الزام حقوقی. نیاز قراردادی/حقوقی، توقف حذف هنگام اختلاف، حق دسترسی و اثر backup باید پیش از انتخاب عدد نهایی بررسی و تصویب شوند.

اثر گزینه کوتاه‌تر: هزینه و حجم داده کمتر، امکان رسیدگی به اختلاف قدیمی کمتر. گزینه بلندتر: بازیابی بهتر با بار بیشتر برای دسترسی، حریم و پاک‌سازی backup. سیاست backup مستقل و در گیت S11 باقی است. پیش از تصمیم، داده واقعی وارد نشود؛ کد این پیشنهاد را خودکار اعمال نمی‌کند.
