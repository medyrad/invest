# runner بازآزمایی مستقل

این پوشه فقط متعلق به `TEST-EXPERIENCE-RETEST-01` است. انتظارها از AC-PC01..08 و قراردادهای 009/010 آمده‌اند و برای تطبیق با رفتار محصول ضعیف نشده‌اند.

اجرا باید روی compose ایزوله `invest-expit`، PostgreSQL مصنوعی و مسیر خروجی همین مأموریت باشد. DB فعال و شواهد تاریخی هدف نوشتن نیستند. trace خام مرورگر ممکن است نشست مصنوعی داشته باشد و با الگوی `*-artifacts/` وارد commit نمی‌شود.

جزئیات image، فرمان دقیق و نتیجه هر اجرا در گزارش و manifest نهایی ثبت می‌شود.

نتیجه نهایی این runner: ۴۵ سناریوی رفتاری یکتا با outcome نهایی ۴۵ قبول، به‌علاوه پنج سناریوی مشاهده/capture. اجرای پایه چهار شکست harness داشت: الزام جدید فرم حرفه‌ای، scroll آیتم منوی بلند، render پرسش شرطی و cleanup پاسخ گم‌شده. انتظارها ثابت ماندند و فقط همان چهار node هدفمند بازاجرا شدند. آزمون مستقل backend برای فارسی‌بودن route عمداً رد محصول را در `backend-route-label.xml` ثبت می‌کند.
