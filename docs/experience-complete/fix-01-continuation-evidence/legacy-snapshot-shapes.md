# ممیزی شکل‌های واقعی snapshot تاریخی گزارش

مبنای بررسی: تاریخچه کد تا commit `2725de9`، fixtureها و مدل `core.Report` در ادامه مأموریت PROGRAMMER-EXPERIENCE-FIX-01. این سند استثنای پذیرش ایجاد نمی‌کند؛ فقط مرز بازسازی بدون داده زنده را ثبت می‌کند.

| شکل | داده واقعاً موجود | بازسازی مجاز | داده ناموجود و رفتار صادقانه |
|---|---|---|---|
| قالب ۱ بدون `report_id` | `template_version=1`، snapshot فرصت شامل `opportunity/assumptions`، `guide_context`، `warning`، `created_at` | عنوان و تمام فیلدهای خام فرصت با واژه‌نامه ثابت `guide-fields-v1.json`؛ بخش‌های پرونده و فرض‌ها | شناسه گزارش، متن گام‌ها و label موقعیتِ ذخیره‌نشده بازسازی نمی‌شوند؛ محدودیت فیلدی فارسی نمایش داده می‌شود |
| قالب ۱ دارای `report_id` | شکل بالا همراه شناسه | همه موارد بالا همراه رسید شناسه | فقط گام‌ها/labelهای واقعاً ناموجود محدود اعلام می‌شوند |
| قالب ۱ دارای `guide_context.answers` خام | پاسخ خام و انتخاب‌های تاریخی؛ بدون `effective_advisory` نسخه‌دار | checkedهای قابل نگاشت به متن snapshot و بخش‌های غیرراهنمایی | پاسخ خام به‌عنوان مؤثر نمایش داده نمی‌شود؛ داده زنده برای تشخیص شرط خوانده نمی‌شود |
| قالب ۲ جاری | افزون بر بالا: `title`، `field_labels`، `action_steps`، `effective_advisory`، `report_id` و `rendered_html` | دانلود بعدی دقیقاً از HTML ثابت snapshot؛ preview و سند از renderer مشترک | هیچ lookup زنده برای پرکردن سابقه انجام نمی‌شود |

واژه‌نامه `guide-fields-v1.json` از schema تاریخی همان قالب منجمد شده و import طرح‌واره زنده نیست. تست‌های `test_real_template_one_snapshot_shapes_are_readable_and_honest` هر دو شکل شناسه، منع نمایش پاسخ خام و متن محدودیت را می‌سنجند. `test_report_document_design_and_effective_content_are_snapshot_only` ثبات در برابر تغییر داده زنده، کارت‌بندی، عنوان، واحد و بخش‌های سند را می‌سنجد. تست مرورگر `actual immutable report...` یک سند واقعی جاری را دانلود و در چهار عرض render می‌کند.

مانع تصمیم بیزینسی: نام فارسی موقعیت یا متن گام اگر هرگز در snapshot قالب ۱ ذخیره نشده، از شواهد تاریخی قابل استنتاج نیست. گزینه‌های ممکن برای تصمیم جداگانه فقط «نمایش شناسه تاریخی با محدودیت» یا «مهاجرت داده با منبع مصوب مستقل» هستند؛ این مأموریت گزینه دوم را جعل یا تصویب نکرده است.
