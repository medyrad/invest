## مسیرهای گزارش و رگرسیون مستقیم

برای investor واقعی با داده مصنوعی، preview، ساخت گزارش، دانلود اول و دریافت مجدد بررسی شد. دو دریافت بایت‌به‌بایت برابر و برابر `rendered_html` منجمد snapshot بودند. عنوان، label/مقدار/واحد «نیاز مالی کل؛ 14.5 میلیارد تومان»، نوع پیگیری فارسی، شرایط متقاضی، بخش پاسخ‌های مؤثر، پرونده کامل و گام‌های اقدام حضور داشتند. محتوای تزریقی escape شد؛ header دانلود CSP شامل `sandbox` داشت؛ حساب دوم 404 گرفت و نشست بی‌اعتبار مجاز نشد. شمار Case قبل و بعد ثابت ماند.

نمونه‌های مستقل هر هشت route در backend بررسی شدند. سفر investor در Chromium واقعی نیز از preview به دانلود اول و صفحه پروفایل/دریافت مجدد رفت؛ label فارسی واقعاً مشاهده شد، enum خام غایب بود، فونت آماده شد و HTML دریافت‌شده دوباره render شد. تصاویر تازه بازبینی بصری شدند. این مشاهده برای رفتار route است و ادعای pixel-perfect یا امضای انسانی طراحی نیست.

رگرسیون محدود renderer شامل عنوان، پاسخ مؤثر، label/واحد، نوع پیگیری، CSP/escaping و redownload بود. ۱۳ node مرتبط خود محصول نیز سبز شدند، اما پذیرش مستقل بر ۱۴ سناریوی مستقل و مشاهده مرورگر تکیه دارد، نه سبزی تست برنامه‌نویس.
